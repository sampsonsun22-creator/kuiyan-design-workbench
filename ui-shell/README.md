# KEY 视界 · 产品壳原型（ui-shell）

浅色「研究实验室」三栏壳。v1 默认已放弃深色 Fancy 主题，对齐用户参考图 + Design Director 浅色 token。

## 布局

| 栏 | 宽度 | 职责 |
|---|---|---|
| 左 | ~240px | 黄底 `{KEY}` 品牌砖、「+ 新建研究」、**能力栈**（编排器 / 采集 / 点点 状态点 + 一行最近动作）、已保存研究列表 |
| 中 | flex | **协作室**：研究问题栏、五层步进、活动时间线（非胖聊天气泡）、底栏黄发送 |
| 右 | ~1.35fr | **画布**：四个页签 Brief / 竞品版图 / 决策筛选 / 结论报告；源状态芯片；同类·不同类·跨界·货架 chip；选中黄框；可折叠检查器（L3 维度，缺值写未标注）|

## 五层与页签

| 层 | 阶段 | 右栏页签 |
|---|---|---|
| L1 意图识别 | 听清 Brief | Brief（分析对象 + 三路搜索计划 vs 已落地）|
| L2 搜索穷尽 | 穷尽搜索 | 竞品版图（同类 / 不同类 / 跨界 / 货架）|
| L3 分类拆解 | 分类拆解 | 同一版图 + 检查器三组维度 |
| L4 决策筛选 | 决策筛选 | 短名单 8–12 款 + 推荐理由 + 批注重筛 |
| L5 结论报告 | 结论报告 | 六段报告，方向假设卡挂在第 5 段 |

ACTIVE = 黄底黑字（`--stage-active-bg: #FFE900`）。口径见 `../AGENT-LAYERS.md`。

## 文件

- `index.html` / `styles.css` / `app.js` — 可点原型（静态，无构建）
- `data/product-bundle.json` / `data/product-pack.json` — 生产 slim 包（L1 + L3 摘要 + 3 张方向假设卡；无 item_catalog）
- `data/classify-dimensions-v1.json` — L3 维度骨架，检查器与 L5 覆盖表都读它
- `data/l2_main_wall.jsonl` / `data/l2_pending_review.jsonl` — 交付锁 452 / 2680
- `assets/ref*.png|jpg` — 方向假设卡本地参考图
- `RESTYLE-LAB.md` — 本次浅色实验室重做说明
- `concept.html` — 旧概念页（非主路径）

## 交互

- 点阶段 / 源芯片 → 刷新右栏 + 活动流追加事件
- 点墙上卡片 → 黄框选中 + 检查器按视觉 / 体验 / 商业三组列字段，没采到写「未标注」
- 决策筛选：自动收 8–12 款带理由；可逐条「拿掉」；写批注按「按批注重筛」＝在已落地 452 张上重排，**不发起新采集**
- 结论报告：六段结构，方向假设卡 Keep/Kill 记在第 5 段
- 发送「看 Brief / 看版图 / 帮我筛选 / 出结论报告」，或直接写批注让它重筛
