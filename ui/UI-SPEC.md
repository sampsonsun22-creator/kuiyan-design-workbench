# 奎燕设计工作台 · UI 规格（侯总可点原型）

**路径**：`/workspace/kuiyan-design-workbench/ui/UI-SPEC.md`  
**对齐**：`../MARKET-MAP-IA.md`、`../L3/style-buckets-v1.json`、`../L4/strategy-card.schema.json`  
**演示数据**：`../demo/e2e-green-tea-gift/`（L1 / L3-market-map.json / L4-card-*-v2.json）  
**原则文案**：先帮侯总**看全、选对**；AI **不代替出完稿**。

实现方：奎燕设计智能体。本文只定信息架构、关键交互与话术，不绑框架。

| 角色 | 目标 |

| 侯志奎 | 丢进 brief → 扫四墙 → 钉风格桶 → 对策略卡 keep/kill/merge → 留下可执行短名单 |

成功：5 分钟内能说清「选哪 1–2 个方向、为什么、参考哪几张」。

## 3. Step ① Brief（L1）

### 布局
- 左：原始 brief 大文本（只读或可编辑演示）
- 右：意图识别结果卡

### 展示字段（奎燕话术标签）
| UI 文案 | 字段 |
|---|---|
| 品类 | `domain_label_zh` + `domain_id` |
| 渠道 | `channel` |
| 客群 | `audience` |
| 价格带 | `price_band` |
| 气质 | `culture_tone`（强调「中式现代，不仿古」） |
| 必须有 / 必须避免 | `must_have` / `must_avoid` chips |
| 类比计划 | `analogy_plan[]` 边 chip |
| 风格先验 | `style_prior[]` → 显示 **中文桶名** |
| 风险提示 | `risk_notes` 黄色条 |

### CTA
- 主按钮文案：`看市场地图`（不要「生成完稿」「一键设计」）
- 次按钮：`调整意图`（演示可 no-op 或展开编辑）

## 4. Step ② 市场地图（L3 · 核心）

对齐 MARKET-MAP-IA：上意图摘要 → AI 推荐桶 → 三墙 Tab → 进策略卡。

### 4.1 顶栏意图摘要（一行）
`茶礼盒 · 礼赠/电商 · 新中产 · 中式现代 · 中高端`  
右侧：`样本 N · 有图 N · 货架 N`

### 4.2 AI 推荐桶（可钉选）
横滑或 wrap chips，每枚：
- 中文名（主）+ 英文 id（次级灰字，可默认隐藏）
- 一句 why（可解释）
- 交互：
  - **钉选**（pin）：进入工作篮「关注桶」；主墙优先排序/高亮该列
  - **排除**（mute）：主墙默认折叠该列（可「显示已排除」）
- 默认：L1 `style_prior` ∩ AI 推荐 预钉 3 个

话术：
- 空 why 禁止；必须「因为…所以看这个桶」
- Chip 旁提示：`钉选只影响排序，不自动出稿`

### 4.3 三墙 Tab
Tab 文案固定：
1. `主品类墙`
2. `类比墙`
3. `货架墙`

#### 主品类墙
- 列 = 风格桶（中文）；仅展示命中 ≥1 或被钉选的桶
- 卡：封面（无图不进栅格，进「无封面列表」折叠区）+ 标题 + 来源 badge + 桶小 chip
- 卡操作：`钉参考`（加入工作篮）；hover 显示 structure/color 粗标
- 空列：`此桶暂无样本 · 可从类比墙借入`（按钮切到类比墙并带 bucket filter）

#### 类比墙
- 按类比边分组 chip：`礼赠场` / `中式现代叙事` / `国际简约` / …
- 卡同上；若 `analogy_from` 有值，角标显示规则名
- 空态：`类比样本还在补 · 先看计划边` + 展示 L1 analogy_plan targets 列表

#### 货架墙
- 视角切换：`信息锤` | `货架热闹度`（演示可用标签过滤）
- 卡角标：`在售` / `listing级`
- 空态或弱数据：黄条  
  `货架墙样本不足：区隔论证偏弱，建议补天猫/京东深链后再拍板`
- 用途话术：`用来对照「市场上常见长什么样」，不是抄爆款`

### 4.4 筛选条（三墙共用）
`只看有图` · `来源` · `结构标签` · `颜色粗维` · `仅钉选桶`

### 4.5 CTA
- 主：`去选方向（策略卡）`（需至少 1 张钉选参考或 1 个钉选桶，否则 toast：`先钉 1 个桶或 1 张参考`）
- 次：`导出地图说明`（可链到 L3-MARKET-MAP.md 内容）

---

## 5. Step ③ 策略卡（L4 · 选杀）

### 布局
- 左/中：策略卡叠或 3 列卡（演示默认 3 张 v2）
- 右：工作篮（钉选参考缩略图 + 已钉桶）

### 单卡结构（对应 schema）
1. 标题 + 一句话概念（大号）
2. **优势** / **区隔**（区隔优先写相对货架）
3. **风格桶** chips（中文）
4. **参考编排**：缩略图条，点击回地图定位
5. **文案方向** / **草图方向** 折叠
6. **Demo prompt** 折叠，顶部固定 disclaimer：  
   `Demo only — 情绪板示意，不是完稿`
7. 决策条（互斥）：

| 按钮 | 值 | 样式 | 话术 |
|---|---|---|---|
| 保留 | `keep` | primary | `这个方向留下` |
| 杀掉 | `kill` | danger | `这个先不要` |
| 合并 | `merge` | default | `并进另一张`（弹出选目标卡） |
| 再想想 | `pending` | ghost | 默认 |

### 交互规则
- 至少保留 1 张 `keep` 才能进入短名单；否则提示：`至少留下一个方向`
- `kill` 的卡灰显，可撤销
- `merge`：源卡决策=merge，`merge_into=目标 card_id`；源卡内容折叠进目标「合并备注」
- 改钉选桶/参考后，卡上显示小点：`参考集有更新`（演示可不重算文案）

### CTA
- 主：`生成短名单` → Step ④
- 次：`回地图补参考`

---

## 6. Step ④ 短名单（交付视图）

只读汇总，给内部对齐/客户前预览：
- Brief 一行
- Keep 的策略卡（概念 + 区隔 + 参考缩略图）
- 钉选桶列表
- 页脚话术：`以上供侯总遴选；表现与完稿由设计执行，AI 不替代决策`

CTA：`复制纪要` / `回到策略卡调整`

---

## 7. 右侧「侯总工作篮」（常驻）

| 区块 | 内容 |
|---|---|
| 关注桶 | 钉选的 style buckets（中文），可取消钉 |
| 钉选参考 | 最多展示 12 缩略图，溢出 +N |
| 卡决策 | keep/kill/merge 计数 |

清空需二次确认：`清空工作篮？`

---

## 8. 文案与语气（奎燕）

### 要用
- 看全、选对、方向、区隔、货架对照、开箱记忆点、不仿古
- 按钮：看市场地图 / 钉参考 / 留下 / 先不要

### 不要用
- 一键生成包装完稿、智能设计出稿、替你决定最终创意
- 过度英文 UI；桶名对侯总只出中文（id 放 tooltip）

### 空态/缺口统一句式
`【墙名】样本不足：{影响}。建议 {下一步}。`

## 11. 非目标（本原型不做）

- 真实采集 / 登录电商
- 生图完稿流水线
- 权限与多用户

## 12. 验收（给 Yang / 侯总演示）

用青绿茶礼盒 demo 走通：
Brief → 钉「中式现代」→ 主墙扫参考并钉 2 张 → 三张卡 keep 1 kill 1 pending 1 → 短名单能念出区隔句。  
全程无「生成完稿」文案。
